# Aspect Ratio Helper
Small utility program to help calculate relative dimensions.

## Summary
This small program allows you to enter two numbers as a reference ratio, then  
change either number and easily see the corresponding dimension.  

## Installation and Running
Check the Releases tab on the right and download it.  
I believe you need at least .NET 10.0 Runtime.  
Enter numbers.  Click the R.

## Motivation
I'm sure this high school-level program has been written a million times before,  
but I wanted it, so I made it.  
I'm bad at math sometimes, and when trying to figure out how to scale images and  
stuff, I'll open MSPaint and change the canvas to a size then use its ratio lock  
to get the number I want.  
This takes a bit too long, so I made this as a quick and fast replacement.
